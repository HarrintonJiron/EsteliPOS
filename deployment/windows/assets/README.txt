Coloque aqui instaladores offline para equipos sin internet.

URL REWRITE (IIS)
-----------------
Archivo: urlrewrite2.exe

Descarga oficial:
https://www.iis.net/downloads/microsoft/url-rewrite

Direct link:
https://download.microsoft.com/download/1/2/8/128E2E0C-1125-48B4-AB5E-829F25AC6235/urlrewrite2.exe

PHP THREAD SAFE (opcional, sin internet)
----------------------------------------
Archivo: php-ts.zip
  (o cualquier php-X.Y.Z-Win32-vs17-x64.zip SIN "-nts-" en el nombre)

Descargue PHP 8.4+ Thread Safe x64 desde:
https://windows.php.net/download/

El instalador lo extrae en C:\EsteliPOS\PHP y lo agrega al PATH.

VISUAL C++ REDISTRIBUTABLE (opcional)
-------------------------------------
Archivo: vc_redist.x64.exe

Direct link:
https://aka.ms/vs/17/release/vc_redist.x64.exe

PHP 8.4+ lo requiere en Windows. El instalador intenta descargarlo solo.

ORDEN DE USO DEL INSTALADOR
---------------------------
1. Usa archivos locales de esta carpeta
2. Intenta descargarlos de internet
3. Muestra instrucciones manuales si falla
