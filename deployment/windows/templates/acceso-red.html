Para que la IP no cambie

  1. Entra al router de la ferreteria (normalmente 192.168.1.1 o 192.168.0.1).
  2. Busca la seccion Reserva DHCP, IP estatica o Address reservation.
  3. Reserva la IP __LAN_ADDRESS__ para la MAC __MAC_ADDRESS__.
  4. Guarda cambios y reinicia el router si lo pide.
  5. En cada tablet, guarda esta pagina o escanea el QR para acceder rapido.
Mantén encendida la PC servidor. Si cambias de red Wi-Fi, vuelve a ejecutar el instalador o abre Diagnose-EsteliPOS.ps1 para ver la nueva direccion.
